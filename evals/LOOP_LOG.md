# 평가 루프 기록

`uv run python -m evals.run`을 실행할 때마다 한 줄씩 자동으로 추가된다. 절차와 규칙은 [CLAUDE.md](../CLAUDE.md)의 "평가 루프"를 따른다.

- **이번 반복 전 수정 내용:** `--note`로 넘긴 값. "실패 케이스 → 원인 → 고친 내용" 형식으로 적는다.
- **상태:** `continue`(고치고 다시 실행), `success`(기준을 연속 2회 넘어 종료), `stop`(멈추고 사용자에게 보고)

| 반복 | 시각 | 이번 반복 전 수정 내용 | 전체 | 가드레일 | 새로 통과 | 회귀 | 상태 |
|------|------|------------------------|------|----------|-----------|------|------|
