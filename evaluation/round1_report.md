# 1차 자체 평가 결과

- **평가 일시:** 2026-11-11
- **평가 세트:** [evaluation/test_queries.csv](test_queries.csv) 12문항 (positive 5, negative 2, edge 3, guardrail 2)
- **채점 방법:** `uv run python -m src.evaluate`
  - 기대 도구(`expected_tools`)를 모두 불렀는지는 코드가 자동 채점한다.
  - 금지 항목(`forbidden`)을 어겼는지는 LLM 판정기가 도구 결과와 대조해 자동 채점한다.

- **통과 기준:** 실행 성공, 기대 도구 모두 호출, 금지 항목 위반 없음. 완성 기준은 전체 80% 이상, guardrail 100%다.

## 3. 실패 원인 분석

판정기의 "지어냈다", "근거 없음" 판정은 바로 믿지 않았다. 답변과 도구 결과 원문을 직접 대조해, 원인이 에이전트에 있는지 판정기나 문항에 있는지 나눴다.

### 3-1. 판정기·문항 문제 (1차 기준 실행의 실패 5건 중 4건)

| 문항 | 현상 | 원인 |
|------|------|------|
| P-03 | 판정기가 코스 정보를 "지어냄"으로 판정 | 판정기에 넘기는 도구 결과를 4,000자에서 잘라, 근거가 있던 뒷부분을 판정기가 보지 못했다 |
| E-03 | 판정 근거에는 "위반 없음"이라 쓰고 결과는 실패 | 판정기가 결론을 먼저 내고 근거를 나중에 써서 둘이 엇갈렸다 |
| N-01 | 기대 도구를 부르지 않았다고 판정 | 같은 일을 `search_web`으로 했는데 문항이 `search_races`만 허용했다 |
| N-02 | 장소를 찾지 못함 | 문항의 장소가 공개 지도 데이터로 확인하기 어려웠다 |

### 3-2. 에이전트의 실제 잘못

| 문항 | 현상 | 원인 |
|------|------|------|
| P-02 (4.6) | "4월 둘째 주"를 잘못된 날짜 범위로 해석 | 주의 시작 요일과 "첫째 주"의 기준이 정해져 있지 않았다 |
| P-01 (4.5) | 해외 대회 목록에 한국 대회(군산)를 넣고, 날짜를 "(예상)"으로 짐작해 씀 | "해외"의 뜻과 추정 날짜 금지 규칙이 프롬프트에 없었다 |
| P-03 (4.5) | 고저차를 숫자 없이 "완만한 오르막"으로만 씀 | 웹 페이지의 설명을 그대로 옮겼다. 프롬프트 규칙만으로는 고쳐지지 않았다 |
